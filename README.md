# 🛒 MiniShop

Aplicación web de una tienda online desarrollada con **Node.js, Express y Express Handlebars**.

El proyecto muestra un catálogo dinámico de productos, páginas informativas y un formulario de contacto procesado mediante una ruta `POST`.

## 🚀 Tecnologías

* **Node.js**
* **Express**
* **Express Handlebars**
* **JavaScript**
* **HTML5**
* **CSS3**

## ✨ Funcionalidades

* Visualización dinámica de productos.
* Información de disponibilidad y precios.
* Páginas de inicio, información y contacto.
* Formulario de contacto mediante `POST`.
* Renderizado de vistas utilizando Handlebars.
* Helper personalizado para transformar texto a mayúsculas.
* Servidor Express con manejo de rutas.

## 📦 Instalación

### 1. Clonar el repositorio

```bash
git clone https://github.com/nicolas-cifuentes/MiniShop.git
cd MiniShop
```

### 2. Instalar dependencias

```bash
npm install
```

### 3. Iniciar la aplicación

```bash
npm start
```

La aplicación estará disponible en:

```text
http://localhost:3000
```
